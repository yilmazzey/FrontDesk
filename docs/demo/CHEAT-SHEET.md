# Demo cheat sheet

**Web opening:** `docs/demo/WEB-SCRIPT.md` — 3 minutes, starting at the desk, with 75 seconds each on the data map and the RAM/performance slide.

**4 minutes. Four scenes. One local app.**

## 0:00 — Landing page (10s)
Open the web page. Say: “A local-first second brain for managers — Pfizer × Newpage.”

## 0:10 — Dashboard + Ask (70s)
- Point: **Next up**, **Open loops**, **Deadlines**, **People**.
- Ask: `What am I waiting on from Zeynep?`
- Point at `[1]` and the source card.
- **Set deadline** → `Zeynep budget sign-off` → Fri 27 Nov, 17:00 → **Set deadline**.
- **Open loops** page → swipe `Send Zeynep the revised launch scope` (or click the drawer) → **Done** → back.

Say: “Next up comes from the calendar, loops from notes and mail. Every answer has a citation. I can turn it into a deadline, and a finished commitment disappears with a swipe.”

## 1:20 — Handwriting (50s)
- **Search** → `pilot sites` → open the `launch-whiteboard` result. Close Preview.
- Ask: `How many pilot sites are we starting with?`
- Point at the citation to the scan.
- **Timeline** → show Today.

Say: “This is a handwritten page. macOS reads it on-device with Apple Vision, so it is searchable. The original never moves.”

## 2:10 — Meeting + privacy (50s)
- **Meetings** → record. Read the script below. **Stop & transcribe**.
- Point at the actions in the notes.
- **Saved** → **Decision** (optional).
- **People** → two clusters; toggle Notes; click Anika → evidence; **Ask FrontDesk about Anika** (optional).
- `⌘⇧P` to blur, again to unblur.

Say: “Recording stays on this Mac. Whisper transcribes locally, the local model writes the notes, audio is deleted. Saved answers are plain Markdown. And the window blurs when someone screen-shares.”

## Meeting script (25s)

> Launch review update. We are keeping phase one small: three pilot sites — Leeds, Manchester and Bristol. Anika will bring the vendor shortlist and final costs on Monday. Zeynep still needs to sign off the budget by Friday the twenty-seventh. Legal needs the data-processing addendum signed before the first pilot goes live. Decision for Monday: Northlight for phase one, with Bramble as the fallback.

## If you have three minutes

Skip the landing page and **Saved**. Keep: Dashboard → Ask → deadline → swipe → scan/search → meeting → People → `⌘⇧P`.

## If Microsoft is not connected

Skip calendar and mail. Use the local notes and scan. Everything else works.
