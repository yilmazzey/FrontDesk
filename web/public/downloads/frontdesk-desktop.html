FrontDesk desktop

Pfizer & Newpage Solutions Hackathon Challenge · Desktop

Take the desk
with you.

The desktop app is where notes, OCR, the local model and your Microsoft account live. The build is small because the window uses the system webview; your files never leave the machine. A language model is optional and downloaded separately.

Download for macOS ↓ All releases → v0.1.0 · unsigned preview

The preview is signed ad-hoc, so macOS asks you to confirm the first launch (System Settings → Privacy & Security → Open Anyway). Windows may show a SmartScreen prompt until a code-signing certificate is added.

Local model (optional) GGUF · 2.3 GB

Installed, the app is about 13 MB. Add a GGUF model only if you want local answers: drop it into the model folder from Settings, or connect an existing Ollama install. With neither, FrontDesk still answers extractively from your files.

01

Local by default

Notes, scans and the search index sit in a folder you choose. The app works with the network switched off.

macOS Windows Linux
02

One permission at a time

Mail, calendar, OCR and the local model are separate switches. Connect Microsoft only when you want it, and revoke it without touching the rest.

03

Answers with receipts

Every answer cites the note, email or page it came from. If the app cannot find the source, it says so instead of guessing.
